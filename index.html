F.A.Q

A compact FAQ for questions people ask right before they were absolutely going to click around and find out anyway.

Is this layout suitable for GitHub Pages?

Yes. It is a single static HTML file with embedded CSS, which means GitHub Pages can host it without demanding a sacrifice.

Can I split CSS into a separate file?

Yes. Move the CSS into style.css, link it in the head, and enjoy the brief illusion of structure.

Can I replace placeholder text and cards?

Yes. Titles, cards, team, FAQ and footer are all easy to edit, break, and then proudly fix again.

Does it require JavaScript?

No. The page is fully static. The FAQ only uses native HTML details and summary, like the web ancestors intended.
