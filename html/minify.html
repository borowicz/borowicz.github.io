What it does

Small, fast, dependency-free.
JSON

Validates the structure, parses it safely in the browser, and outputs a compact one-line JSON string.

JavaScript

Uses a lightweight whitespace/comment compactor. Good for utility snippets, not a replacement for a full AST minifier like Terser.

HTML

Collapses redundant whitespace between tags and trims noisy spacing. It avoids pretending to be a full HTML compiler.

CSS

Removes comments and excess whitespace, then tightens separators so your styles stop taking the scenic route.

Browser-only

No backend, no upload, no server detour. Your pasted content stays in the page.

GitHub Pages friendly

One file, no build step, no drama. Drop it into a repo and publish.

Note: JavaScript minification here is intentionally simple. For production bundling, use a real parser/minifier. For quick browser-side utility pages, this is fast and practical.
