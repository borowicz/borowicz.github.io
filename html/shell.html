🛠️ General shell

Files, text, logs, system, Git, and terminal tricks

Twenty practical one-liners for daily terminal work. Useful for cleanup, searching, text processing, diagnostics, Git housekeeping, and quick shell shortcuts.

🧹 Find and delete all empty directories

find . -type d -empty -delete
filescleanupfind

📦 Find the 10 largest files in the current folder

du -ah . | sort -rh | head -n 10
filesdisk usagesorting

📝 Batch rename file extensions, for example from .txt to .md

rename 's/\.txt$/\.md/' *.txt
renamefilesbatch

💾 Create a quick backup of a file

cp file.txt{,.bak}
backupcopyfiles

🔢 Extract unique lines from a file and count occurrences

sort file.txt | uniq -c | sort -nr
textuniqsorting

🪵 Follow logs in real time and highlight the word Error

tail -f access.log | grep --color=always "Error"
logstailgrep

🧽 Remove duplicate lines without sorting and preserve order

awk '!visited[$0]++' file.txt
awktextdedupe

🔁 Replace all occurrences of one phrase with another in many files

sed -i 's/old/new/g' *.txt
sedreplacetext

🚪 Check which process is using a given port, for example 8080

lsof -i :8080

📊 Show the most frequently used commands from shell history

history | awk '{print $2}' | sort | uniq -c | sort -rn | head -10

🔎 Find text in all project files with line numbers

🏗️ Create a whole project folder structure in one shot
