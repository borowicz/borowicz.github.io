Make it yours

A little CSV to start with.

Try the custom date and event import with a small example dataset. The dates and descriptions are fictional placeholders, not an official holiday calendar.

Download sample CSV ↧

The file uses date,everyYear,description. Use MM-DD with true for a recurring yearly event, or YYYY-MM-DD with false for a one-time event. Edit the rows before importing them in the app’s Dates & Events settings.
