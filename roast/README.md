# RoastOS — GitHub Pages

Static landing page for RoastOS.

## Publish on GitHub Pages

1. Create a repository, e.g. `RoastOS`.
2. Upload the contents of this directory to the repository root.
3. In **Settings → Pages**, select **Deploy from a branch** and choose `main` / root.
4. The site will be available through GitHub Pages.

The page is dependency-free apart from Google Fonts and uses graphics extracted from the provided RoastOS/MacRoast project archive.
