# lastOpened GitHub Pages

Static, bilingual EN/PL landing page for **lastOpened**.

## Included

- `index.html` — complete site with embedded CSS and JavaScript
- `lastOpened.png` — original product screenshot used in the hero section
- `social-preview.png` — Open Graph / X preview
- `favicon.svg`

## Design

The palette uses a restrained pastel-green system:

- warm off-white background `#F4F7EE`
- pale sage sections `#E8EFDF`
- dark graphite-green text `#202820`
- primary forest accent `#41664A`
- soft pistachio accent `#C9D8AF`

The original application screenshot is shown without cropping or recoloring.

## Publish with GitHub Pages

Copy the files to the publishing branch or `/docs` directory, then select that source in **Settings → Pages**.
