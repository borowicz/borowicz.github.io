# MŚ 2026 — terminarz TVP na GitHub Pages

Statyczna strona z terminarzem meczów MŚ 2026, filtrami i plikiem ICS.

## Publikacja na GitHub Pages

1. Utwórz repozytorium, np. `ms2026`.
2. Wrzuć pliki: `index.html`, `matches.js`, `ms2026-wszystkie-mecze-tvp.ics`.
3. Wejdź w **Settings → Pages**.
4. Source: **Deploy from a branch**.
5. Branch: `main`, folder `/root`.
6. Po chwili strona będzie dostępna jako `https://twoj-login.github.io/ms2026/`.
